# 🌤️ F Weather

A simple **real-time weather web app** that detects the user's location using the browser, fetches address details from **OpenStreetMap (Nominatim)**, and retrieves live weather data + 7-day forecast from **Open-Meteo API**.

---

## 🚀 Features
- 🌍 Auto-detects location using `navigator.geolocation`
- 📍 Fetches **city & state** automatically
- 🌡️ Shows real-time temperature, windspeed & weather condition
- 📅 Displays 7-day forecast
- 🎨 Auto background update based on weather
- 📱 Mobile responsive layout
- ⚡ **No backend needed** — fully browser based

## ▶️ Run Locally (No Install)
> Just open the HTML file

1. Download or clone the project
2. Open `index.html` in any browser
3. Allow location access
4. Weather data will load automatically 🎯

---

## 🌐 Deploy / Host (Free Options)

### **GitHub Pages**
1. Push folder to a GitHub repository
2. Go to **Settings → Pages**
3. Choose `main` branch → `/root`
4. Save and get your live URL

### **Netlify**
- Drag & drop the project folder at: **https://netlify.app/drop**

### **Vercel**
- Import repo to Vercel → Deploy → Done!
